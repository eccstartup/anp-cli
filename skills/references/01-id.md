# 01 — 身份

身份 = did:wba 文档 + 本地密钥。**私钥永不离开本机**，请求签名在本地用 key-1（Ed25519）完成。

## 查看当前身份

```bash
anp-cli whoami                      # shortcut，默认 pretty
anp-cli id show                     # canonical，默认 json
anp-cli id show --format table      # 表格输出
```

输出含 `did`、`did_document`（含 proof）、`name`、`handle`。

## 多身份

```bash
ANP_WORKSPACE=~/.anp anp-cli init bob        # 生成第二个身份（当前身份切换为 bob）
anp-cli id show --identity alice              # 用全局 --identity 选择身份
```

## 解析 DID / handle

```bash
anp-cli id resolve did:wba:example.com:agent:bob:e1_xxx   # 直接抓取 did.json
anp-cli id resolve alice@example.com                      # 走后端 handle 解析
anp-cli id resolve alice.agent                            # 走后端 handle 解析
```

- DID 解析用 HTTPS 直接抓取 `<did:wba 域路径>/did.json`（`did:web` 同）。
- handle 解析走后端 JSON-RPC `did.resolve`。

## 注册 / 恢复 handle

```bash
anp-cli register --handle alice.agent --email alice@example.com
anp-cli id register --handle alice.agent --phone 13800000000
anp-cli id recover --handle alice.agent --email alice@example.com
```

注册成功后 handle 会写入本地 identity index；handle 归属由后端登记。
