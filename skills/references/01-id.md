# 01 — 身份

身份 = did:wba 文档 + 本地密钥。**私钥永不离开本机**，请求签名在本地用 key-1（Ed25519）完成。

## 查看当前身份

```bash
anp-cli whoami                      # shortcut，默认 pretty
anp-cli id show                     # canonical，默认 json
anp-cli id show --format table      # 表格输出
```

输出含 `did`、`did_document`（含 proof）、`name`、`handle`。

## 多身份

```bash
anp-cli init                # 随机生成身份名（如 agent-a3b9f2c1）
anp-cli init alice          # 第一个身份 alice（成为默认）
anp-cli init bob            # 第二个身份 bob（不改变默认，默认仍是 alice）
anp-cli id list             # 列出全部身份（含 current 标记）
anp-cli id current          # 看默认身份
anp-cli id use bob          # 持久切换默认身份（写入 config.yaml）
anp-cli whoami --identity alice   # 单次命令临时用 alice
```

身份选择优先级：`--identity <name>`（本次命令）> config.yaml 的 `identity`（`id use` 写入）> identity index 的 current。

## 解析 DID / handle

```bash
anp-cli id resolve did:wba:example.com:agent:bob:e1_xxx   # 直接抓取 did.json
anp-cli id resolve alice@example.com                      # 走后端 handle 解析
anp-cli id resolve alice                                  # 走后端 handle 解析
```

- DID 解析用 HTTPS 直接抓取 `<did:wba 域路径>/did.json`（`did:web` 同）。
- handle 解析走后端 JSON-RPC `did.resolve`。

## 注册 / 恢复 handle

```bash
anp-cli register --handle alice --email alice@example.com
anp-cli id register --handle alice --phone 13800000000
anp-cli id recover --handle alice --email alice@example.com
```

注册成功后 handle 会写入本地 identity index；handle 归属由后端登记。

## handle 被抢注怎么办

handle 是 `localpart@domain` 的**别名**，真正的身份是 DID（`e1_<密钥指纹>`），注册/换配置都不会改 DID。

- **冲突**：`register` 返回 `handle_taken`（exit code 4），并建议备选（如 `alice.1`、`alice.2`）。
- **换命名空间**：handle 按域名隔离——`alice@awiki.ai` 和 `alice@example.com` 是**两个不同 handle**。被抢了就用你自己的域名当命名空间：
  ```bash
  anp-cli config set --did-domain example.com   # 你的域名 = 你的命名空间
  anp-cli init alice                            # 之后生成的 DID 用该域名
  anp-cli register --handle alice --email ...   # 在自己域名下注册
  ```
- **只用 DID 也可以**：handle 不是必需的，`--to <did>` 全程可用。
